START HERE

1. Configure backend/PostgresTableViewer.Api/appsettings.json (or set ConnectionStrings__Postgres).
2. Terminal 1:
   cd backend/PostgresTableViewer.Api
   dotnet restore
   dotnet run
3. Terminal 2:
   cd frontend
   npm install
   npm run dev
4. Open http://localhost:5173

Read README.md for all setup steps, endpoints, and security notes.
